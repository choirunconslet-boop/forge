A standalone GitHub-compatible git forge in one Node process — git smart HTTP (clone/push), REST v3 API, GraphQL v4 and MCP tools, all served from its own in-memory store. No git binary, no package manager, no database: the standard library plus vendored source only.

## Run it

```sh
node --experimental-strip-types main.ts
```
